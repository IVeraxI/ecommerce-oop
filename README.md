# E-commerce OOP

Ядро для интернет-магазина на основе ООП-подхода. Проект реализует базовые сущности
электронной торговли: товары и категории товаров.

## Функционал

- Класс `Product` — представление товара (название, описание, цена, количество).
- Класс `Category` — представление категории товаров со списком объектов `Product`.
- Атрибуты класса `Category.category_count` и `Category.product_count` автоматически
  считают количество категорий и товаров при создании новых объектов.
- Функция `load_categories_from_json` — загрузка категорий и товаров из JSON-файла
  (`products.json`) с автоматическим созданием объектов `Category` и `Product`.

## Тестирование

Для запуска тестов используется библиотека `pytest`.

### Запуск тестов

\`\`\`bash
poetry run pytest
\`\`\`

### Запуск с отчётом о покрытии

\`\`\`bash
poetry run pytest --cov=src --cov-report=html
\`\`\`

Отчёт покрытия сохраняется в папку `htmlcov/`.

### Покрытие кода

Функциональный код покрыт тестами на 100%.
